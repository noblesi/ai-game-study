## 2025-12-01 파이썬 공부 로그

### 오늘 한 것
- `unit_logic.py` 리팩토링 전 버전 코드 확인
  - `search_unit_menu_for_select` 흐름과 내부에서만 쓰이던 출력 로직 구조 파악
  - 검색 → 결과 출력 → 번호 선택 → 인덱스 반환까지의 전체 플로우 다시 정리
- 2차 리팩토링 방향 설계
  - 검색 결과 한 줄 출력, 전체 목록 출력 등을 공통 함수로 분리하는 구조 구상
  - 유닛 한 줄 표기를 위한 `format_unit_brief` 같은 공용 포맷 함수 아이디어 정리
  - 검색 결과를 `(원본 인덱스, Unit)` 튜플 리스트로 다루는 현재 구조를 유지하면서, 출력/선택 부분만 더 깔끔하게 분리하는 방식으로 설계
- 입력/선택 유틸 활용 계획 정리
  - `utils.py`에 정의된 `input_non_empty`, `input_int`, `select_from_list` 등을 적극 사용해서
    - 중복되는 입력 검증 코드 줄이기
    - 검색 결과에서 번호 선택하는 부분을 공통 패턴으로 통일하는 방향 잡기
- `edit_unit_menu` 개선 포인트 파악
  - 메뉴 번호 입력을 두 번 받던 버그/중복 코드 확인
  - 이름/레벨/HP/ATK 수정 시 공통적인 출력 형식과 검증 흐름을 어떻게 맞출지 구상
