## 2025-12-20 AI, 파이썬 공부 로그

### 오늘 한 것
- `train_baseline.py`를 “평가 리포터” 형태로 확장
  - K=10 반복 평가에서 모델별 지표를 수집하고 요약(mean/min/max) 출력
  - 불균형 데이터 대응 지표 추가
    - accuracy / balanced accuracy
    - label=1 기준 precision / recall / f1
    - confusion matrix 누적(TN/FP/FN/TP) 출력
- 모델 비교 범위 확장
  - MAJORITY_SPLIT, LogisticRegression(기본/balanced), DecisionTree(balanced), RandomForest(balanced_subsample) 비교
- best 모델 자동 선택 + 피처 랭킹 출력까지 연결
  - f1_1(mean) 기준으로 best 모델 선택
  - best 모델을 전체 데이터로 재학습한 뒤
    - 트리 계열: feature_importances_
    - 로지스틱 회귀: |coef| 기반
    으로 Top feature 랭킹 출력
- 결과 리포트(.md) 자동 생성
  - `reports/baseline_eval_YYYYMMDD.md` 생성 및 best/top-features 섹션 append 확인

### 어려웠던 점 / 체크포인트
- 불균형 데이터에서는 accuracy만으로 성능 판단이 어려움 → balanced accuracy, f1_1을 함께 보는 구조로 정착
- 트리 계열 모델 성능이 매우 높게 나와(거의 1.0 근접)
  - 다음 단계에서는 “pair 단위 그룹 분할(Group Split)”로 암기/누수 가능성을 점검하는 것이 중요
- Top feature에서 `ttk_adv`, `d_ttk_est` 등이 크게 나옴
  - 파생 피처(전투 의미 기반)가 실제로 예측에 강하게 기여함을 확인
