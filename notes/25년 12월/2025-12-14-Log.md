## 2025-12-14 파이썬 공부 로그

### 오늘 한 것
- 전투 시뮬레이션 로직을 `unit_logic.py`에서 분리해 `battle_sim.py`로 모듈화
  - `simulate_duel(1D)`, `simulate_duel_2d(2D)`, `print_battle_summary`, `build_experiment_summary` 이동
  - 전투 계산 로직(타겟 타입/사거리 판정/이동/공격 이벤트)을 "순수 로직"으로 정리
- `unit_logic.py`는 메뉴/UI 흐름 중심으로 정리
  - 전투/실험/시나리오 메뉴에서 `battle_sim.py`의 함수들을 import해서 호출하도록 변경
  - 중복 정의/덮어쓰기 문제(동일 함수가 여러 번 정의되는 문제) 제거
- 내부용(underscore) 함수 노출 개선
  - `battle_sim.py`에 공개 API 래퍼 추가
    - `find_unit_by_name_fuzzy`, `make_unit_from_spec`, `run_duel_trials_2d` 등
  - `unit_logic.py`에서는 underscore 함수 직접 import 없이 공개 API만 사용하도록 정리
- `main.py` 상단 설명 문구를 최신 구조에 맞게 수정
  - “전투 계산 로직은 battle_sim.py, 메뉴/UI는 unit_logic.py”로 역할 명확화

### 어려웠던 점 / 체크 포인트
- `unit_logic.py`에 전투 함수가 남아있으면 import한 함수를 덮어써서,
  “분리한 듯 보이는데 실제로는 분리가 안 된 상태”가 되기 쉬움 → 중복 정의를 반드시 제거해야 함
- underscore 함수(`_find_*`)를 외부에서 import하면 구조가 금방 깨지기 쉬워서
  공개 API 래퍼로 정리하는 게 유지보수에 유리했음
