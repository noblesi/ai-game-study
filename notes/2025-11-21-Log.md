## 2025-11-21 파이썬 공부 로그

### 오늘 한 것
- input()으로 문자열 입력 받고 int(), float()로 숫자형으로 변환하는 연습
- while True 루프에서 break, continue를 사용해 반복 흐름 제어하는 법 연습
- 콘솔 기반 간단 계산기 프로그램 구현
  - 메뉴(더하기/빼기/곱하기/나누기/종료) 선택 구조 작성
  - 잘못된 메뉴 입력 시 continue로 다시 선택하게 처리
  - 나누기 연산 시 0으로 나누는 경우 예외 처리
- 유닛 관리 메뉴 프로그램 구현
  - 유닛 정보를 딕셔너리로 관리하고 리스트에 저장
  - 유닛 목록 출력, 유닛 추가, 선택한 유닛 레벨 업 기능 구현
  - 인덱스 범위 검사로 잘못된 번호 입력 시 처리
### 어려웠던 점
- while True 루프에서 종료 조건을 if로 분기하고 break로 빠져나오는 흐름이 처음엔 헷갈렸음
- 메뉴 번호를 잘못 입력했을 때 continue로 다시 메뉴 선택 단계로 돌아가게 만드는 흐름을 설계하는 데 시간이 조금 걸렸음
- 유닛 관리 프로그램에서 리스트의 인덱스가 범위를 벗어났을 때 어떻게 방어 코드를 짜야 할지 고민이 필요했음
