# 2026-01-03 AI, 파이썬

## 오늘 한 것
- `.\run_pipeline.ps1` 실행 실패 로그 확인
  - `CommandNotFoundException` 발생(스크립트/명령어를 찾지 못함)
- 원인 정리: 실행 정책 문제가 아니라 **파일 경로 문제** 가능성이 큼
- 실행 경로 가이드 정리
  - 현재 폴더에서 `.\scripts\run_pipeline.ps1` 형태로 실행하도록 안내
  - `pwd`, `ls .\scripts`, `Get-ChildItem -Recurse -Filter run_pipeline.ps1` 로 위치 확인하도록 정리
- (추가 대응) 만약 이후 `PSSecurityException`이 뜰 때만 `Set-ExecutionPolicy -Scope Process Bypass` 사용하도록 체크포인트 정리

## 어려웠던 점 / 체크포인트
- PowerShell 에러가 “정책(UnauthorizedAccess)”이 아니라 “경로/파일 없음(CommandNotFound)”일 때는
  - `Set-ExecutionPolicy`부터 만지지 말고
  - `pwd` / `ls` / `Get-ChildItem`으로 **스크립트 위치부터 확정**하는 게 우선
- 실행 커맨드는 프로젝트 구조에 따라 달라질 수 있으니
  - `defense-balancing-tool` 루트에 없으면 보통 `scripts` 폴더를 먼저 의심
