## 2025-11-20 파이썬 공부 로그

### 오늘 한 것
- if / elif / else로 나이와 유닛 상태 분기 로직 복습
- for, while 기본 문법 학습
  - range, enumerate 사용해서 리스트 순회
  - while + break/continue로 루프 제어
- 텍스트 전투 루프 미니 프로젝트 구현
  - 플레이어/몬스터 상태를 딕셔너리로 관리
  - 턴 기반 전투 흐름 작성
  - 행동 선택(공격/방어/도망) 입력 처리

### 어려웠던 점
- while 루프에서 탈출 조건을 생각하는 게 헷갈렸음
- 잘못된 입력에 대해 continue로 다시 선택하게 만드는 부분에서 흐름을 몇 번 틀림
