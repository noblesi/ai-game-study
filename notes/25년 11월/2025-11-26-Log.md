## 2025-11-26 파이썬 공부 로그

### 오늘 한 것
- 유닛 관리 프로그램 구조 리팩터링
  - `Unit` 클래스를 도입하여 기존 딕셔너리 기반 유닛 데이터를 객체 기반으로 변경
  - 파일 구조를 `main.py`, `unit_model.py`, `unit_io.py`, `unit_logic.py`로 분리하여 역할을 명확히 정리(진입점 / 모델 / 파일 IO / 유닛 로직)
- JSON 파일 입출력 로직 개선
  - `Unit.to_dict()` / `Unit.from_dict()`를 사용해 클래스와 JSON 데이터 간 변환 처리
  - 파일이 없거나(JSON 파일 없음), JSON 형식이 깨진 경우 예외 처리 후 빈 리스트로 안전하게 시작하도록 유지
- 유닛 검색 및 선택 기능 고도화
  - 이름(또는 일부 문자열)로 유닛을 검색했을 때, 결과가 여러 개인 경우 목록을 출력하고 번호를 선택해 특정 유닛만 조작할 수 있게 구현
  - 선택된 유닛에 대해 레벨업, 삭제 기능이 정상적으로 작동하도록 연동
  - 메뉴 번호 중복, `__main__` 조건 비교 오타, `save_units_to_file`에서의 오타 등 자잘한 버그 수정

### 어려웠던 점
- 기존 딕셔너리 기반 코드에서 클래스로 전환하면서, 각 파일 간 import 관계와 타입 힌트를 정리하는 과정이 헷갈렸음
- 검색 함수가 단일 유닛 반환에서 "여러 개 리스트 반환" 방식으로 바뀌면서, 이를 사용하는 레벨업/삭제/검색 메뉴 로직도 함께 손봐야 했음
- 검색 결과가 여러 개일 때 번호 선택, 잘못된 입력 처리, 0번 입력 시 취소 등 입력 흐름을 깔끔하게 만드는 데 생각보다 조건 분기가 많이 필요했음
