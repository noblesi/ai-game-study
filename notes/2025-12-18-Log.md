- 로그 파이프라인 “끝까지” 검증 완료
  - `validate_logs.py`로 v1 로그 검증을 수행하고, 누락 이슈(legacy 시나리오 로그에 `scenario_spec` 없음)를 확인
  - A안(새로 생성) 방향으로 v1 형식 로그를 다시 쌓는 흐름을 정리
- 데이터셋/학습 베이스라인 실행 성공
  - `export_dataset.py`로 JSONL → CSV 데이터셋 생성

    - input rows / usable rows가 동일(전처리 스킵 없음)
