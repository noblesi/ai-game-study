## 2025-12-17 파이썬 공부 로그

### 오늘 한 것
- 로그 스키마 v1 패치(최소 변경) 적용
  - `unit_logic.py`에 공통 메타(`schema_version`, `engine`, `run_id`, `spec_source`)를 생성/기록하는 방식 추가
  - `analyze_logs.py` 리포트에 schema/engine/run_id 표시 + schema 분포(legacy/v1) 경고 추가
- legacy JSONL → v1 마이그레이션 스크립트 추가
  - `migrate_logs.py`로 누락 필드 보정(run_id, engine, spec_source, logged_at 등)
  - inplace 백업(.bak-타임스탬프) 후 덮어쓰기 지원
- JSONL → CSV 데이터셋 export 스크립트 추가
  - `export_dataset.py`로 전투 요약(summary) + 유닛 피처(attacker/defender) + 라벨 생성
  - `scenario_preset`, `auto_experiment`를 필터링하여 통합 export 가능

### 어려웠던 점 / 체크포인트
- 기존(legacy) 로그와 v1 로그가 섞이는 구간이 생기므로:
  - 리포트에서 혼합 여부를 경고로 보여주고
  - 마이그레이션을 한 번 돌려 “데이터셋 생성 파이프라인”을 안정화하는 게 중요
- `engine/spec_source`는 legacy 로그에서 완벽 추정이 어려워서 보수적으로 `unknown` 처리하는 정책이 필요
- CSV export는 “컬럼 고정(일관성)”이 중요해서, 유닛 dict가 없을 때도 컬럼을 유지하도록 처리
