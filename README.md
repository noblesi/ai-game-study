# AI & Game Study

이 레포는 AI와 게임 개발을 결합하기 위한 공부 기록을 정리하는 공간입니다.

## 폴더 구조

- `notebooks/` : 파이썬, Numpy, 머신러닝, 딥러닝 등의 실습 노트북
- `notes/` : 수학, 알고리즘, 논문/강의 정리 등 텍스트 기록
- `data/` : 실습에 사용되는 예제 데이터셋 (작은 크기 위주)

## 목표

- 2026년까지 AI를 활용하는 게임 개발자 또는 AI 관련 엔지니어로 취업 가능한 수준의 역량을 갖추는 것.
- 학습 과정을 꾸준히 기록하고, 포트폴리오에 참고 가능한 실습 결과를 남기는 것.
